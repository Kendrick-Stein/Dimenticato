# Progress

## What Works
- Italian portal is feature-rich and production-like
- German portal supports vocabulary practice, grammar book access, and basic progress/settings
- English portal supports vocabulary practice, grammar book access, and basic progress/settings
- Custom wordbooks can be imported, managed, and studied locally
- Community wordbooks support upload, browse, preview, and import workflows
- Grammar reading works through precompiled datasets
- Italian conjugation and verb collocation modules are present
- Data backup/import-export exists and has been expanded for multi-language support

## Recent Evolution
- Project expanded from Italian-only into a three-language app
- Language switching moved into the sidebar rather than a dedicated landing portal
- German and English were upgraded from skeletons to usable learning modules
- Community wordbooks became language-aware within a shared pool
- Navigation/back behavior was aligned more closely across language modules

## Partial / Incomplete Areas
- Italian remains much more complete than German and English
- German and English grammar modules are narrower than the Italian feature set
- Community features depend on external Supabase availability
- Some multi-language areas still appear to be converging toward unified patterns rather than fully settled

## Known Active Concerns
- Difficulty may need to be increased in practice modes
- More confusable distractors and Chinese-prompt-driven recall are desired
- Documentation should stay aligned with ongoing multi-language changes
